|                                                                                                 |
|   Porting Guide - Doom 64 EX to Doom 64 Retribution                                             |
|_________________________________________________________________________________________________|


---------------------------------------------------------------------------------------------------
   PART 1: Copying Geometry and Cleanup
---------------------------------------------------------------------------------------------------

 1) Create a new UDMF format map in your editor of choice (DB2, GZDB or GZDB-BF).

       NOTE: Your editor must support taking in paste data from other editors!

 2) Open Doom Builder 64, and then open the map you want to port over.

 3) In the original map, go into Sectors Mode and highlight over the entire map to select
    ALL sectors. Press Ctrl+C to copy all the sectors.

 4) In the UDMF map, paste the sectors with Ctrl+V and then press C to clear.

 5) In the original map, find a vertex to reference (i.e. uppermost left corner vertex).

 6) In the UDMF map, switch to Vertices Mode and select ALL vertices. Locate the vertex
    reference from the previous step and move ALL vertices at once to match with the
    identical coordinates from the original map.

       NOTE: The purpose of this is to ensure all vertices are at the same exact position
             as in the original level. This also factors into the correct original texture
             alignment of the floors and ceilings.

 7) In the UDMF map, switch to Sectors Mode and select ALL sectors once again.

 8) Right-click to edit sectors and do each of the following:

      • Enter 0 in the effects box to clear all sector effects
      • Enter 0 in the tag box to clear all sector tags

      NOTE: None of the original effects or line actions are the same and thus are NOT
            compatible. Clearing tags will make sure you will only tag the sectors
            which are required.

 9) In the UDMF map, switch to Linedefs Mode and select ALL linedefs.

10) Right-click to edit linedefs and do each of the following:

       • Enter 0 in the action box to clear all line actions
       • Enter 0 in the tag box to clear all line tags
       • Clear checkboxes for:
           - Doublesided
           - Impassable
           - Upper and Lower Unpegged
           - Block Monster
           - Shown as 1-sided on map
           - Not shown on map
           - Repeatable action
           - Activation types (player walks over, player presses use, etc.)

11) While still editing linedefs, check the box for ALL lines to be double-sided
    even if some are not and are against the void.

12) Exit edit linedefs and press C to clear selection.

13) Go into Map Analysis Mode and run it. Right click any of the entries "Linedef x is
    marked double-sided but has no back side" and then click "select results of this
    type" and then click Make Single-Sided.

       NOTE: You may need to fix map errors before you can do all of these at once. Some
             warnings might include a missing sidedef, unclosed sectors, and such. Fix
             these first if you cannot fix all the lines at once.

14) In the original map, go into Things Mode and highlight to select ALL things, then
    press Ctrl+C to copy them.

15) In the UDMF map, go into Things Mode and press Ctrl+V to paste the things, then
    press C to clear the edit selection.

16) Re-select all things by highlighting over, then drag them to line up with their
    original positions. It should be obvious how they all fit once you start to drag
    them closer. Refer to the original map if needed.

17) While the things are still selected, right-click and open the edit things menu.
    Check off Skill 1-5, Class 1-5, and Single Player and Co-op flags. Clear the
    Deathmatch flag if it is set. Stay in Things Mode.


Now you have the 100% accurate geometry and all things where they belong, next comes the actual map fixing.
We don't need to worry about the majority of textures thanks to the textures in Doom 64 Retribution being
named after the same textures that Doom 64 EX uses. We will however need to worry about textures which were
mirrored or flipped, which will be done in the next part.


---------------------------------------------------------------------------------------------------
   PART 2: Setting up the Map
---------------------------------------------------------------------------------------------------

 1) In the original map, switch to Things Mode and then change the Things Filter to Easy skill.

 2) In the UDMF map, select all things that are shown from the filter in the original map.

 3) Right-click and edit things, set these things to Skill 1 and Skill 2.

 4) Repeat steps 1-3 for Medium skill and Hard skill.

       TIP: Remember, the way Doom does skills is that Easy skills are 1 and 2, Medium is 3,
            and Hard is 4 and 5. This means that things which appear on Skill 1 will also be
            on Skill 2, every thing on Skill 4 will also be on Skill 5, and finally Skill 3
            can vary.

       NOTE: Some things may be monsters or items which spawn in later on during map
             progression. I would worry about this later while you are actually making
             the map playable again since it will be easier and faster to tell. Also
             some monsters may be set to be "deaf" or ambush monsters.

       FOR MONSTERS THAT SPAWN IN:

          I would suggest editing your Builder64.cfg file and adding a custom filter to find
          things with the "Spawner" flag set. At least, I think I had to add this myself.
          The config file is located in your User folder, inside AppData\Local\Doom Builder.

             filter6
             {
                name = "Spawners";
                category = "";
                type = -1;

                fields
                {
                   32 = true;
                }
             }

          Once this is added, you can use it to figure out very quickly which things are
          spawners and set them to MapSpots now or just remember them for later when you
          get to this step.


6) Some things will need to be changed out to new versions used by Doom 64 Retribution.
   As an example, if your EX map uses torches that means you have a torch base thing and
   a floating fire thing. This method caused issues in GZDoom and thus I have created
   some combined versions of all possible combinations.

   Refer to this quick table to know what will need to get changed:
       _________________________________________________________________________________
      | If you have...                                    | Change to...                |
      |===================================================|=============================|
      | 1050 and 1033 (Torch Base Long and Blue Fire)     | 15001 (Torch Long Blue)     |
      | 1050 and 1034 (Torch Base Long and Red Fire)      | 15002 (Torch Long Red)      |
      | 1050 and 1035 (Torch Base Long and Yellow Fire)   | 15003 (Torch Long Yellow)   |
      | 1051 and 1033 (Torch Base Short and Blue Fire)    | 15005 (Torch Short Blue)    |
      | 1051 and 1034 (Torch Base Short and Red Fire)     | 15006 (Torch Short Red)     |
      | 1051 and 1035 (Torch Base Short and Yellow Fire)  | 15007 (Torch Short Yellow)  |
      | 89 (Trigger)                                      | Linedef or sector actions   |
      | 2050 (Projectile Spot)                            | 9001 (MapSpot) + script     |
      |___________________________________________________|_____________________________|

   There are also green torches you can use instead. The single floating fires are still
   things which can be used if you so desire.

7) In the original map, go into Visual Mode and check around the map for textures that
   are mirrored or flipped. If you are familiar with the Doom 64 textures, you won't
   need to check the linedef for the mirror flags since you should know what they
   look like when mirrored.

   While doing this, when you find one that's mirrored, go in the UDMF map and into
   Visual Mode and change the corresponding texture to the mirrored version. I've
   named the mirrored versions by usually adding a 1 to the end (i.e. C57 is C571).

8) Do the same as step 5, except this time for switches. I've compiled most if not
   all of the original configurations of switches and textures into custom composite
   textures with the right texture and switch. If your map uses a new configuration
   that was not already present, you will need to create it yourself.

      NOTE: Refer to the main WAD to see how I did them. I would advise you do NOT
            name yours as the next number (i.e. don't name yours CMPSW43A if the
            last one is CMPSW42A). I may end up adding more later!


---------------------------------------------------------------------------------------------------
   PART 3 - "Making" the Map
---------------------------------------------------------------------------------------------------

Now for the most tedious step of all. Actually re-making the map.

Play through the map in EX, and while you are doing that, in the UDMF map you will be fixing the map
to make it work again just like the original map. You will need to script things which require it,
re-assign the right actions and basically re-make the map. The hardest part is syncing everything
to behave like Doom 64. It can't be perfect but you can get it VERY close.

If you can, I would suggest refering to the original macro scripts to be absolutely sure what happens
and when, using the original map in Doom Builder 64 as your reference.


---------------------------------------------------------------------------------------------------
   PART 4 - Coloring the Map
---------------------------------------------------------------------------------------------------

The final step is lighting and coloring. All your sectors are 255 brightness and no color. Compare the
map in EX and find similar colors and brightness levels. Some sectors may change depending on actions
or scripts, so you will need to fix that as you make the map by writing scripts to modify the sector
colors and lighting.

If you want to use the GZDoom Doom 64-like color properties, it will be a lot easier to get the correct
colors. Check each sector in Doom Builder 64 and get the RGB values. Unfortunately the paste data from
copying colors within the Edit Sector window does not travel outside of the edit window, including
between sectors IN the editor. This means you have to go RGB by RGB. This would be an excellent update
to Doom Builder 64 in the future, where it can use HEX values and actually copy to the clipboard like
GZDoom Builder does. One can hope.
