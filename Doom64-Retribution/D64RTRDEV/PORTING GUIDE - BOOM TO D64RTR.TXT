|   Porting Guide - Absolution TC (Boom format) to Doom 64 Retribution                            |
|_________________________________________________________________________________________________|

There are several overall steps to converting a Boom format map from the Absolution TC (or any
Boom map) to Doom 64 Retribution's standards, or UDMF. Here is a simple outline of the steps:

   Step 1 - Converting to UDMF and fixing map errors
   Step 2 - Re-texturing with Doom 64 Retribution's texture set (very tedious)
   Step 3 - Recreating the actual map, recoloring, and changing things
   Step 4 - Playtesting and tweaking for preference


Here's the exact step-by-step how-to:

1) Open the Boom formatted map, and go to Edit >> Map Options. Change the game configuration to
   GZDoom: Doom 2 (UDMF) and script type of ZDoom ACS script. Change the level name if necessary.
   Click Yes on the prompt warning the map is a different file format.

1) Go into Linedefs mode and select all lines, then do each of the following in order:
      • Clear checkboxes of Doublesided, Upper and Lower unpegged, Impassable, Block monsters,
        shown as 1-sided on map, and Not shown on map
      • Set the Action box to 0 to clear all incompatible Boom actions
      • Clear checkboxes of Repeatable action and activation types
      • Set all tags to 0
      • On front side page, right click each texture screen to clear all textures of all front
        sides, then set the texture offsets to 0, 0 on all
      • Do the same thing for back side. You may also need to reset scales.
   Press OK

2) Go back into Linedefs mode again and re-select all lines, then set them all to double sided
   even if they border the void and should not be.

3) Go into Sectors mode and select all sectors, then do each of the following:
      • Set the Special box to 0
      • Set all tags to 0
      • Leave brightness alone for now (will tweak later)
      • Go to Surfaces and right click floor and ceiling to clear the textures
   Press OK

4) Go into Things mode and select all things, then do each of the following:
      • Uncheck Deathmatch
      • Check Class 1-5
   Press OK

5) Go into Map Analysis Mode and run it. Right click any of the entries "Linedef x is
   marked double-sided but has no back side" and then click "select results of this
   type" and then click Make Single-Sided.

   NOTE: You may need to fix map errors before you can do all of these at once. Some
         warnings might include a missing sidedef, unclosed sectors, and such. Fix
         these first if you cannot fix all the lines at once.

6) OPTIONAL:
   Go into Make Sectors Mode and navigate to the outside dummy sectors and click on
   each of them to separate them from the rest of the map. We are using UDMF, so
   dummy sectors for map effects are useless unless for 3D floors or other UDMF
   specific effects. These sectors with scrolling floors for voodoo dolls and
   teleporting monsters are no longer needed. Then go into Sectors Mode and
   delete these useless sectors and any things inside them.

7) You now have a blank slate to work with and the map is ready to be converted to
   Doom 64 Retribution. However, many things and actors will most likely be wrong
   and will be using the Doom 2 originals. Since Retribution does not replace all
   the original Doom 2 actors and instead uses Doom 64's DoomEd numbers, this means
   that you will need to manually run Find and Replace Mode for some thing types to
   match them back up.

      NOTE: Refer to the list of thing types from Absolution TC to Retribution below.

   I would also suggest you change all brightness levels to the ones in the list
   below since the Absolution TC uses much darker values which don't translate
   well to GZDoom. Also run Find and Replace to correct some things which have
   weird angles and the ambush flag when it's not needed.

8) Re-texture the whole map. This task is hard and can be quite daunting. Believe me,
   you do NOT want to sit in the Absolution TC playing it and constantly ALT-tabbing
   between the game and the editor. So, do this to make it easy on yourself:

   [a] First, set up the Boom configuration in GZDB to use the main Doom 64 data WAD
       from the old TC. The filename and path is: Bin\Data\doom64\doom64_abstin.wad

   [b] Using this file will show you exactly what textures are used where in the map
       so that you can just look in map editor instead of needing to be in-game.

   [c] This is only for textures, but believe me, doing the textures is the hardest
       and most tedious step because you have to basically re-paint the whole map.
       When you get really detailed maps, this takes time. Using this method will
       significantly cut down on time spent texturing.

   [d] Just keep this open, and open a new window of GZDB and open your UDMF map
       in that one, and keep swapping between visual modes and do each area. This
       also allows you to use the visual mode camera to see where the in-game
       player cam cannot.


For these final steps, you WILL need to go in-game.

 9) Re-make the map using UDMF features and ACS scripts. Lucky for us, Boom maps
    are somewhat limited in features, which means it will be easier to recreate
    a Boom map in Doom 64 Retribution than it is to do an EX map, mostly.

10) Re-color the whole map. Again, luckily this version of Doom 64 was somewhat
    limited with the color options since it only created the ones required for
    the original maps. New maps made for it might add new colors, however.

       NOTE: Refer to the list below for a rough list of some of the colors
             and matching light levels used in Absolution TC maps.

==========================================================================
   COMMON COLOR HEX VALUES FOR FAST COLORING (WITH CLOSE LIGHT LEVELS)
   USE THESE FOR CLOSE APPROXIMATIONS FOR DOING COLORS
==========================================================================

   FORMAT IS:
   (color hex), (light level) = (resulting color and specific uses, if any)

--- DOOR COLORS ----------------------------------------------------------
FF4040, 255 = light red, for red doors and exit sign sectors
00A0FF, 255 = light blue, for blue doors
FFFF00, 255 = full yellow, for yellow doors

--- PURPLE ---------------------------------------------------------------
64A0E6, 255 = purple-ish color for special spots
8CB4F0, 180 = for lights in dark blue indoors
82A0F0, 130 = dark purple for dark indoor areas
D2D2FF, 180 = very light purple for monitors

--- AQUAMARINE AND CYAN --------------------------------------------------
96F0E6, 130 = aquamarine main room color
96F0F0, 200 = lights in aquamarine rooms
8CC8C8, 130 = greenish blue dark for outside areas

--- BLUE -----------------------------------------------------------------
96C8F0, 200 = blue color for outside sky sectors (space sky) or blue sectors
8CC8F0, 120 = dark blue for indoor dark rooms

--- GREEN ----------------------------------------------------------------
A0FF8C, 140 = greenish rooms color 1
D2FF8C, 140 = same as above but more yellowish
8CDC64, 160 = hard green for monitors
CDF9CA, 200 = nukage lighter
A4FF77, 180 = nukage greener

--- YELLOW ---------------------------------------------------------------
D2E678, 160 = yellow green color for monitors
E6E650, 200 = lighter yellow for monitors
F0F082, 200 = same as above, slightly whiter
DCE678, 160 = greenish slightly yellow for doorways
E6D278, 150 = darkened yellow monitor

--- YELLOW/ORANGE/RED ----------------------------------------------------
FAC896, 130 = yellow orange main color
F0A064, 200 = lights in yellowish orange sectors and in front of doors
F07846, 200 = orange red casting light
F0B464, 150 = brighter yellowish for rooms
FADC96, 120 = darker yellowish for rooms

--- PINK-RED -------------------------------------------------------------
FFB4B4, 130 = lightish pink red
FAB4A5, 160 = lightish pink for monitors
