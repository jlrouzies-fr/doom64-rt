 NOTES:
• Please read and follow these instructions very carefully!
• They are important for correct configuration and music setup.
• These steps assume you have already set up GZDoom and have an IWAD.


--- INTRODUCTION --------------------------------------------------------------

The very first thing to do is unzip the ZIP file of the TC. You can unzip the
file right in your Downloads folder if you like. We just need all of the files
inside to be out of the ZIP file.

Now you need to determine which set of steps to follow.

Check your GZDoom folder and version for a "soundfonts" folder. Newer versions
of GZDoom now include FluidSynth by default and supply a default folder for
placing your own soundfonts. If you see "fluidsynth.dll" or some variation
already present, please follow the steps for METHOD A.

If your GZDoom folder and version is old enough, you will not see a
soundfonts folder or a FluidSynth DLL already present. Please follow
the steps for METHOD B instead if this applies to you.


--- METHOD A (NEWER GZDOOM) ---------------------------------------------------

Since modern GZDoom versions have done away with FMOD, they've included and set
up FluidSynth as the default MIDI device. If your version if new enough, there
is also a "soundfonts" folder. Please follow these steps very carefully!

   1) Copy or move the following files to your GZDoom port folder:

         D64RTR[v1.5].WAD
         D64RTR_BRIGHTMAPS.PK3

   2) Copy or move DOOMSND.SF2 into the "soundfonts" folder. If this
      folder does not exist, you can create it. It should be located
      inside the same folder as the "gzdoom.exe" file.

   3) Copy, move or delete the text files and icon. You may be
      interested in keeping the "D64RTRDEV" folder if you would
      like to make your own levels for the TC.

   4) Run the game. Refer to the section below on running the mod.

   5) When in-game, make sure the following settings are correctly set:

         Options --> Sound Options --> MIDI Device --> FluidSynth
         MIDI Player Options --> FluidSynth --> Select Configuration --> DOOMSND.SF2

   6) Verify the music is working by listening to the soundtrack
      elsewhere (like on YouTube) and making sure it sounds the same.
      The simplest way is to listen to the titlemap theme music.

      If it is set up incorrectly, the music will sound like random
      bells and dings instead of the expected ambient sounds.

         NOTE: If you have problems using the SF2 or FluidSynth or are
               on a system which does not support it, refer to the
               section below on the alternative music option.


--- METHOD B (OLDER GZDOOM) ---------------------------------------------------

Older versions of GZDoom (such as 2.4.0) have slightly different steps to
setting up the TC correctly. Please follow these very carefully!

   1) Copy or move the following files to your GZDoom port folder:

         D64RTR[v1.5].WAD
         D64RTR_BRIGHTMAPS.PK3
         DOOMSND.SF2

   2) If you are on a version of GZDoom before fluidsynth was included
      by default, you also need to copy or move this file:

         32-bit GZDoom: libfluidsynth.dll
         64-bit GZDoom: libfluidsynth64.dll

      Do NOT copy both! Only the one that matches your GZDoom.

      NOTES:
        • The text files (like this one) are optional
        • Do not use both DLLs at the same time, if your GZDoom is
          32-bit use "libfluidsynth.dll"; inversely if your GZDoom
          is 64-bit use "libfluidsynth64.dll"
        • The SF2 and DLL files are required for the music to work
        • The DLL file MUST be located directly beside "gzdoom.exe"
        • If you are already familiar with FluidSynth and already
          have it set up, only copy the WAD and SF2

   3) Copy, move, or delete the text files and icon. You may be
      interested in keeping the "D64RTRDEV" folder if you would
      like to make your own levels for the TC.

   4) Open your "gzdoom-NAME.ini" file and press CTRL+F and search
      for keyword "patchset". You will see a cvar setting called
      "fluid_patchset". This will need to read as:

            fluid_patchset=DOOMSND.SF2

      Or if the SF2 is in a subfolder:

            fluid_patchset=subfolder\DOOMSND.SF2

      Make this change, then save your INI file. If this is not set,
      the music playback will sound very wrong! Once you have made
      this change, you are done.

   5) Run the game. Refer to the section below on running the mod.

   6) Verify the music is working by listening to the soundtrack
      elsewhere (like on YouTube) and making sure it sounds correct.
      The simplest way is to listen to the titlemap theme music.

      If it is set up incorrectly, the music will sound like random
      bells and dings instead of the expected ambient sounds.

         NOTE: If you have problems using the SF2 or FluidSynth or are
               on a system which does not support it, refer to the
               section below on the alternative music option.


--- RUNNING THE MOD -----------------------------------------------------------

The simplest way to play the mod is to drag and drop the WAD file
directly over "gzdoom.exe" and it will run automatically.

You can also run it via your favorite mod launcher, or my personal
suggestion is to drop the file into a subfolder (like one called
"custom" as an example) and then run the mod via a batch file.

Creating a batch file is simple, it's basically just a text file
with ".bat" as the extension. All you need to do is right-click
anywhere in the folder you want it to go and select "New" and then
"Text Document." Put whatever you want to go inside it and save it,
then rename it from ".txt" to ".bat" and you are done.

Assuming the mod file is in a subfolder called custom, you can run
the following in a Windows batch file:

      @echo off
      start gzdoom.exe -file custom\D64RTR[v1.5].WAD

IMPORTANT NOTE: Using -file is the recommended method of loading!
As of version 1.5, the mod no longer runs as an IWAD.

Place this batch file directly beside "gzdoom.exe" and name it
whatever you want and double click it to play the mod.


OPTIONAL: If you want to load the brightmaps automatically,
you can add this into the autoload section of the INI file:

      [Global.Autoload]
      Path=D64RTR_BRIGHTMAPS.PK3

Or if the file is in a subfolder:

      [Global.Autoload]
      Path=subfolder\D64RTR_BRIGHTMAPS.PK3

You are done! Enjoy playing the mod!


--- ALTERNATIVE MUSIC OPTION --------------------------------------------------

If for whatever reason you are unable to use the SF2 and FluidSynth, they just
won't work, or you are on an operating system that does not support it, you
will need to use the alternative method for correct music playback.

The alternative choice is simply a pack of the soundtrack recorded into OGG
format which GZDoom can play without needing anything else to play it. The
main reason for treating this option as a alternative choice instead of the
first choice is because the MIDIs of the music in the WAD are direct from the
source files, and the DOOMSND.SF2 is the soundfont used by Doom 64 EX to play
back the music as intended. Plus, the MIDIs have slightly better quality.

Go to the page below and download the file called "D64MUS.ZIP".

   https://www.moddb.com/mods/doom-64-retribution/addons/doom-64-retribution-ogg-music-pack-v13

Once downloaded, copy or move this pack to be with the main WAD and brightmaps PK3.
Run this file the same way as you would the main WAD file and any other addons.
